#  Sistema de Gerenciamento de Tarefas (Java)

Projeto desenvolvido em Java com o objetivo de praticar lógica de programação e conceitos de orientação a objetos, permitindo o gerenciamento de tarefas via terminal.

---

##  Funcionalidades

*  Adicionar tarefas
*  Listar tarefas
*  Marcar tarefa como concluída
*  Remover tarefa
*  Menu interativo no terminal

---

##  Conceitos aplicados

* Programação Orientada a Objetos (POO)
* Uso de classes e objetos
* Estruturas de dados (ArrayList)
* Estruturas de controle (if, switch, loops)
* Entrada de dados com Scanner

---

## 💻 Tecnologias utilizadas

* Java
* VS Code
